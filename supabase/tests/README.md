# فحص المخطط محليًا

هذه اختبارات دخانية للمخطط على PostgreSQL محلي باستخدام PGlite. تُنشئ بدائل بسيطة لـ `auth` و`storage` وأدوارًا وهمية وقاعدة مؤقتة داخل الذاكرة. لا تستخدم قاعدة المتجر ولا أي أسرار.

```bash
npm ci
npm test
```

البيانات المستخدمة وهمية. هذا الفحص لا يختبر Supabase Auth أو Storage API أو Realtime الفعلي، ولا يثبت تعطيل التسجيل العام أو توافق جهاز أندرويد. لا يُغني عن اختبارات مشروع Supabase التجريبي المنفصل وعن فحوص الإصدار النهائي.
